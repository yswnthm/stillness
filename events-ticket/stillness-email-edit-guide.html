Locating The Snippet

Where to find the email code

Unlike regular pages that are built visually in Elementor, the booking confirmation email is deeply integrated into the checkout process. Its layout and text are generated using a dedicated WordPress code snippet.

  1. Log into your WordPress admin dashboard.
  2. In the left-hand menu, locate and click on Snippets.
  3. Look for the snippet named stillness_render_featured_event and click Edit.
  4. Scroll down towards the bottom half of the code file to find the HTML markup for the email.

Making Changes

How to edit the text

Once you are inside the snippet, you will see a mix of HTML tags (like <div>) and the actual readable English text of your email. You can safely change the English words as long as you do not touch the surrounding code tags.

Hero Message

Look for: "Your space has been held." You can change this to any phrase you prefer.

Notes Section

Look for: "A Few Things to Hold" and the paragraph detailing arrival times and what to wear.

Sign-Off Phrase

Look for: "Stillness is not a luxury. It is where you begin again." near the very bottom.

Important Warning

Safeguards & Checklist

Warning: Code snippets are fragile. Removing a single quotation mark or angle bracket can cause the site or email to break. Proceed with care!

  • Never delete or modify any tags wrapped in angle brackets, like <td> or </div>.
  • Never delete PHP tags, which look like <?php echo esc_html( $first_name ); ?>. These insert dynamic data (like the customer's name or event details).
  • Never remove quotation marks around styles.
  • Only modify the plain white text (or colored text, depending on your code editor theme) that represents the human-readable English copy.
  • When finished, click Update to save the snippet, and perform a test checkout to verify the email looks correct.
